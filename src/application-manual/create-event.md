# Create and Publish an Event

Create one event for a meeting, webinar, workshop, or another occasion. You can offer calendar saving, collect registrations, or combine both.

## 1. Start with a group

Open **Events** and choose **Create Event**, or open a group and choose **Create Event here**. Select an existing **Event Group** or create one during setup.

Use a clear group name that will still make sense when you have many events. It is there to help your team organize its work.

## 2. Choose what visitors can do

| Setting | When to use it |
| :--- | :--- |
| **RSVP** | Collect attendance responses. Select or create an [RSVP template](/application-manual/rsvp-forms). |
| **Add to Calendar Button** | Let visitors save the date. In RSVP flows, this also controls the calendar button available after registration. |
| **Event Distribution** | Include event details and calendar files in the RSVP flow. Turning it off also hides calendar buttons. |
| **Call to Action (CTA)** | Add a [follow-up message or action](/application-manual/cta-templates) to calendar sharing. |

For a simple “save the date”, start with the calendar button. For a workshop with places to reserve, enable RSVP.

## 3. Enter the event details

Write a recognizable **Title**. Add a **Description** explaining what happens, who it is for, and anything attendees need to prepare. Put the venue or joining link in **Location**.

Choose the start and end date, the times if needed, and the event's **Time zone**. For an all-day event, leave the time fields empty. Use the time zone of the event rather than assuming every attendee lives in yours.

Locations named **Online**, **Global**, or **Worldwide** cause the landing page to display the time in the visitor's local time zone. Calendar saving still uses the event's time-zone information.

Formatting may vary between calendar providers. Keep essential details understandable even without bold text, lists, or other formatting.

## 4. Choose the right date structure

- **One date:** a single appointment or an event spanning consecutive days.
- **Additional dates:** separate parts, such as a two-session workshop. Give the series a title and review each date.
- **Recurrence:** a regular pattern, such as every week. Use **Simplified** settings to choose the interval and an end date or number of occurrences.

Multiple date blocks and recurrence cannot be combined. If people need to register separately for each session, create separate RSVP events.

## 5. Preview, save, and publish

Choose the style and any templates, then review the preview. Save the event as a draft first; choose **Publish** when it is ready. If saving highlights an invalid field, correct it and save again.

After publishing, allow **3–10 minutes** for updates to reach the sharing systems. Open the landing page and check the title, local time, location, and registration flow before sending the link to your audience.
