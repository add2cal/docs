# Customize Event Landing Pages

A landing page gives you one link to share your event or RSVP form. A **Landing Page Template** customizes that page while the event continues to supply its dates and other details.

## Create and connect a page template

1. Open **Templates → Landing Pages** and create a template.
2. Enter an **Internal Name** your team can recognize.
3. Add a **Title**, **Intro**, and any **Legal notes** you need.
4. Choose a header image, highlight color, and background.
5. Save, select the template in the event's **Landing Page Template** field, and publish the event.

A subscription group can also use a landing page template. Preview a real linked event before sharing it, especially if the template is reused for several dates.

## Make the page useful to visitors

Use the introduction for information people need before acting: who the event is for, what to bring, or where the online session takes place. Keep the event title and date in the event itself so there is one place to update them.

The background can be a solid color, gradient, image, or preset. Choose colors that keep the text easy to read. The image picker accepts JPG, PNG, GIF, and WebP files under 1 MB.

A **Countdown** can appear as a large header or small banner. Preview it with the event you intend to publish, not only the editor's sample event.

## Set search and sharing text

Under **Meta / SEO**, use **Meta title override** and **Meta description override** to write a clear title and short description for search and sharing previews. Mention the event topic and audience naturally.

Use **Disallow search engines to index the page** when you do not want the page included in search results. This requests exclusion from search; it does not make the event private or prevent someone sharing the URL.

Social networks may keep an older preview after you update the event. First check the live page itself, then follow the [preview troubleshooting steps](/application-manual/troubleshooting#social-preview).

## Choose a custom domain

If custom domains are available for your organization, select the **Landing page specific custom Domain** or use the global default. The domain must already be configured for your organization; typing a different URL into a message does not configure it.

## Passwords and private events

A template password protects the **landing page only**. Direct calendar links and calendar files are not protected by that password. To stop public event delivery, use the event's **Set private** action; this also disables its public button and RSVP form.

For RSVP events, the normal landing page displays registration. To share the calendar-saving view instead, add `?type=share` to its URL, provided **Event Distribution** is enabled. Check that you really want this sharing flow before sending it to an audience that should register.
