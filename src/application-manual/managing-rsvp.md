# Manage RSVP Responses and Attendee Lists

Open the event's **RSVP Answers** view to see registrations and attendee details. You can reach it from the event overview or the summary at the top of the event.

## Understand the numbers

An **entry** is one response. **People** counts the attendees represented by those responses. If one person reserves three places, that is one entry and three people.

| Status | Meaning |
| :--- | :--- |
| **Confirmed** | A positive attendance response. |
| **Undecided** | The person selected “maybe”. |
| **Declined** | The person is not attending. |
| **Pending** | The email confirmation step has not been completed. |

Pending entries temporarily occupy places. They are not included in the other statistics and do not appear in the response table. Unconfirmed entries are removed after approximately **20–30 minutes**.

Check the status breakdown rather than treating every response as a confirmed attendee. The page also displays the form's maximum attendance and expiration information.

## Find a response

Use the status selector and search box to narrow the table. Sort a column to review responses by creation date or another displayed value. Open **Details** to inspect the person's additional answers.

A notice about an edited RSVP template means the questions changed after someone registered. Their earlier answer has not been lost, but it may refer to the previous wording or fields. Avoid renaming field identifiers during an active registration campaign.

## Help someone make a change

The **Self-Service URL** leads to that attendee's response-management page. Share it only with the intended person, not in a public message or a shared attendee list.

You can also use the row's edit action to change supported fields. Some fields are not editable. Review the confirmation before saving: an administrative edit **sends an email to the attendee** informing them of the change.

For changes to the event itself, such as a new start time, edit the event and use **Publish + inform** when offered. That is separate from editing one attendee's response.

## Export the attendee list

Choose **CSV Export** for spreadsheet software or **JSON Export** for a technical workflow. The export covers the event's responses; do not assume the table's current search or status filter limits the downloaded file.

Open the file and filter by attendance status before using it as a check-in list. Keep custom answers and email addresses available only to people who need them for the event.

## Remove responses carefully

**Delete all entries** permanently removes the event's non-pending responses. It is not a filter reset and cannot be undone. Export any records you need before using it.

For another session with a fresh attendee list, create a separate event and reuse the [RSVP template](/application-manual/rsvp-forms).
