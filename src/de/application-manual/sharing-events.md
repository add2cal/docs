# Event-Links und Kalender-Buttons teilen

Öffne ein veröffentlichtes Event. Oben findest du die Zusammenfassung mit den Möglichkeiten zum Teilen. Du kannst einen Link ohne eigene Webseite verschicken oder das Event in eine bestehende Webseite einbinden.

## Passendes Format auswählen

| Format | Geeignet für |
| :--- | :--- |
| **Landingpage** | Social-Media-Beiträge, Nachrichten und einen gemeinsamen Link zu Details oder Anmeldung. |
| **E-Mail-Links** | Newsletter und E-Mail-Buttons zum Kalender- oder RSVP-Ablauf. |
| **Integration / ProKey** | Einen Button oder ein RSVP-Formular auf deiner Webseite. |
| **ics-Datei** | Einen Kalenderanhang zum manuellen Importieren. |

## Landingpage teilen

1. Öffne das Event und suche **Landingpage** in der Zusammenfassung.
2. Öffne die Seite selbst und prüfe das Ergebnis.
3. Kopiere die URL in deine Nachricht oder deinen Beitrag.

Bei RSVP-Events beginnt auf dieser Seite die Anmeldung. Mit einem [Landingpage-Template](/de/application-manual/landing-pages) passt du Einführung und Aussehen an.

Verwende keine Informationen, die nicht weitergeleitet werden sollen. Empfänger können einen veröffentlichten Link mit anderen teilen.

## Links in E-Mails einsetzen

Öffne **E-Mail-Links** und wähle die Darstellung, etwa Button, Button-Liste oder Text. Kopiere sie mit einem Desktop-Browser in deinen E-Mail-Editor. Über die direkten Links erhältst du URLs für eigene E-Mail-Buttons.

Schicke dir über dein E-Mail-System eine Testnachricht. E-Mail-Programme, insbesondere Outlook, können das Design unterschiedlich darstellen. Fehlen Bilder, probiere eine Textdarstellung oder die Option für **img-Tags**. Externe Bilder erscheinen unter Umständen erst, wenn der Empfänger das Laden erlaubt.

Die E-Mail-Darstellungen sind bewusst einfacher als Website-Buttons. Du musst kein JavaScript in die E-Mail einbauen.

## Button oder Formular auf der Webseite

Öffne **Integration** und kopiere den **ProKey** oder die angezeigten Codebeispiele. Gib den Key und die [Anleitung für dein Website-System](/de/integration/general) an dein Webseiten-Team weiter.

Für ein einzelnes Event verwendest du dessen **Event-ProKey**. Für ein Kalender-Abonnement oder eine öffentliche Liste brauchst du den **Gruppen-ProKey**.

## Kalenderdatei verwenden

Die **ics-Datei** kann als E-Mail-Anhang verschickt werden. Direkte Datei-Downloads erscheinen nicht in der Statistik der Kalender-Klicks. Nutze dafür den bereitgestellten iCal-E-Mail-Link, wenn du den messbaren Ablauf benötigst.

## Nach Änderungen am Event

Veröffentliche die Änderungen und warte einige Minuten. Die bestehenden Event-Links bleiben verwendbar. Eine schon heruntergeladene Datei oder ein importierter Kalendereintrag ist jedoch eine eigene Kopie. Wenn fortlaufende Aktualisierungen wichtig sind, eignet sich ein [Kalender-Abonnement](/de/application-manual/calendar-subscriptions).
