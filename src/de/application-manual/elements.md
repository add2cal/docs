# Erste Schritte mit Add to Calendar PRO

Beginne mit einem Event: Es enthält die Informationen, die du teilen möchtest, oder den Anlass, für den sich Menschen anmelden sollen. Aussehen und Anmeldeoptionen kannst du dabei direkt festlegen.

Du musst nicht erst alle Bereiche der App einrichten, bevor du dein erstes Event veröffentlichst.

## Was möchtest du erreichen?

| Dein Ziel | Passende Anleitung |
| :--- | :--- |
| Menschen sollen einen Termin im Kalender speichern | [Event erstellen](/de/application-manual/create-event) |
| Anmeldungen oder Rückmeldungen sammeln | [RSVP-Formular einrichten](/de/application-manual/rsvp-forms) |
| Einen fortlaufenden Kalender zum Abonnieren anbieten | [Kalender-Abonnement erstellen](/de/application-manual/calendar-subscriptions) |
| Mehrere Events auf einer Webseite anzeigen | [Öffentliche Event-Liste erstellen](/de/application-manual/event-list) |
| Teilnehmer finden oder Antworten herunterladen | [RSVP-Antworten verwalten](/de/application-manual/managing-rsvp) |

## So passen die Bausteine zusammen

Eine **Event-Gruppe** hält zusammengehörige Events zusammen, etwa „Webinare“ oder „Vereinstreffen“. Jedes Event gehört zu einer Gruppe. Eine Gruppe kann zusätzlich ein Kalender-Abonnement oder eine öffentliche Event-Liste bereitstellen.

Ein **Event** enthält Titel, Termine, Ort und Beschreibung. Sein **ProKey** verbindet das veröffentlichte Event mit dem Button, dem Formular und den Links zum Teilen.

Ein **Style** bestimmt Aussehen, Sprache und Kalender-Auswahl. Ein **Template** stellt wiederverwendbare Inhalte oder Funktionen bereit:

- **RSVP-Template:** Anmeldefragen, Teilnehmergrenzen und E-Mail-Optionen.
- **E-Mail-Template:** Text und Gestaltung einer bestimmten RSVP-E-Mail.
- **Landingpage-Template:** Die Seite, die Besucher über deinen Event-Link öffnen.
- **CTA-Template:** Eine anschließende Nachricht, ein Link, eine Teilen-Funktion oder ein Formular.

Ein Event kann einen Style und mehrere Templates verwenden. E-Mail-Templates werden über das RSVP-Template verknüpft.

## Einstellungen bewusst wiederverwenden

Du kannst denselben Style oder dasselbe Template mit mehreren Events verbinden. So verwenden beispielsweise alle Webinare dieselben Markenfarben und Anmeldefragen.

Die Verbindungen bleiben bestehen. Wenn du ein gemeinsam genutztes Element bearbeitest, kann sich das auf andere verknüpfte Events auswirken. Prüfe vor dem Speichern die **Nutzung** und Hinweise zu verbundenen Elementen. Für eine einzelne Abweichung erstellst du einen eigenen Style oder ein eigenes Template.

## Orientierung in der App

Unter **Events** findest du Events und Gruppen, unter **Styles** die Gestaltung und unter **Templates** wiederverwendbare Inhalte. **Team** verwaltet Kollegen; **Einstellungen** betrifft dein Konto und die Organisation.

Fehlen dir Hinweise in der App, deaktiviere **Hinweise ausblenden** unter **Einstellungen → Benutzer**. Bei fehlenden Events oder unerwarteten Ergebnissen hilft die [Fehlerbehebung](/de/application-manual/troubleshooting).
