# Eine Nachricht oder Aktion nach dem Kalender-Klick

Ein **Call-to-Action (CTA)** bietet Besuchern im Kalender-Ablauf einen nächsten Schritt. Du kannst etwa auf Vorbereitungsmaterial verweisen oder zum Teilen des Events einladen.

Der CTA gehört zum Ablauf beim Teilen. Er beweist nicht, dass die Person den abschließenden Speicherschritt in ihrer Kalender-App durchgeführt hat.

## Den passenden Typ wählen

| Typ | Beispiel |
| :--- | :--- |
| **Text** | „Wir freuen uns auf dich. Bitte komm zehn Minuten früher.“ |
| **Link** | Ein Button zu einer Seite mit Workshop-Vorbereitung. |
| **Teilen** | Die Einladung, das Event mit anderen zu teilen. |
| **Formular** | Ein Formular, das Angaben an einen eingerichteten Dienst übermittelt. |

## CTA erstellen und verbinden

1. Öffne **Templates → CTA** und erstelle ein Template.
2. Vergib einen **Internen Namen** und wähle den **Typ**.
3. Schreibe eine kurze **Überschrift** und einen **Text** mit einem klaren nächsten Schritt.
4. Trage bei einem Link die Ziel-**URL** und einen verständlichen **Button-Text** ein.
5. Speichere das Template.
6. Öffne das Event, aktiviere **Call-to-Action (CTA)**, wähle das Template und veröffentliche.

Auch Abonnement-Gruppen können einen CTA verwenden. Teste mit dem tatsächlichen Event oder Abonnement, da die Kalender-Optionen von dessen Einstellungen abhängen.

## Ergebnis prüfen

Verwende die Vorschauaktion im CTA-Editor und teste anschließend den veröffentlichten Ablauf. Prüfe Links auf dem Smartphone und am Computer.

Halte die Nachricht kurz. „Vorbereitung lesen“ erklärt mehr als ein Button namens „Hier klicken“. Das grundlegende Aussehen kommt aus dem verknüpften Style.

## Wenn du ein Formular benötigst

Die **URL** muss ein Ziel sein, das die gesendeten Formularfelder entgegennehmen kann. Eine normale Webseitenadresse reicht dafür nicht automatisch. Frage das Team, das den empfangenden Dienst betreut.

Ergänze Felder mit stabilen **Namen** und verständlichen **Labels** für Besucher. Wähle Typ, Standardwert und Pflichtangaben nach Bedarf. Zusammengehörige Radio-Auswahlmöglichkeiten stehen direkt nacheinander.

Ein CTA-Formular ist von RSVP getrennt. Für Platzreservierungen und Teilnehmerlisten verwendest du ein [RSVP-Formular](/de/application-manual/rsvp-forms).

Stimme bei einer Newsletter-Anmeldung zuerst mit eurem Newsletter-Team ab, wie Übermittlung und Bestätigung funktionieren sollen. Das technische Übertragungsformat ist in der [CTA-API-Referenz](/de/api/cta) beschrieben.

## CTA wiederverwenden

Prüfe die **Nutzung**, bevor du ein gemeinsam verwendetes Template änderst. Benötigt nur ein Event einen anderen Text oder ein anderes Ziel, erstelle einen separaten CTA und verbinde ihn mit diesem Event.
